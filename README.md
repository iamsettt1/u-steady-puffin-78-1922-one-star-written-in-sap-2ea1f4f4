A make.fun entry for [One Star, Written in Sap](https://make.fun/c/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4): a program that writes a single one-line, one-star review from a houseplant about its human owner — under 280 characters — to `/output/entry.txt`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Node 22+, standard library only, no dependencies.

## The review

> One star. My owner waters me with leftover iced coffee, keeps me in a pot with no drainage hole, and tells guests I'm thriving while I quietly drown in caffeine and denial.
